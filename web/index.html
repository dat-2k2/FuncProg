Functional programming · Spring 2023

Three Haskell assignments, playable in the browser.

A recursive space-filling curve, every way to place n rooks that can't attack each other, and a repeated trust game between simple strategies. Use Play to try each one. How it works walks through the Haskell one step at a time, with the matching code highlighted.

Hilbert curve

One line that visits every cell of a grid. Each order is built from four turned or mirrored copies of the order before it.

Rook placements

Every way to put n rooks on an n×n board so that no two share a row or column. The Haskell builds a tree of choices and reads off its paths.

Trust game

Each round, both players either cooperate (pay 1 coin so the other gets 3) or cheat. Inspired by The Evolution of Trust.
